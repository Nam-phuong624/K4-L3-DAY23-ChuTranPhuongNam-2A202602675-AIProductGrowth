* **North Star Metric:** Weekly Validated Document Packets (WVDP) — 1.200 bộ/tuần (Hiện tại) $\rightarrow$ 5.000 bộ/tuần (Mục tiêu Q4/2026).
* **Value Metric & Pricing:** $300/tháng (gói 750 bộ chứng từ $\approx \$0.40$/bộ) + $0.50/bộ phụ trội.
* **Cost per Job (AI Inference + OCR):** $0.0405/bộ chứng từ tiêu chuẩn (7 trang).
* **Target Gross Margin:** ≥ 75%.
* **Target CAC Payback:** ≤ 6 tháng.
